# KazToGo

Приложение для тех, кто переезжает из России в Казахстан: шаги, сроки, блокнот и гид. PWA без сборки и бэкенда, данные хранятся в браузере.

- Приложение: https://slu1garden.github.io/kaztogo/
- Дизайн-система и токены: https://slu1garden.github.io/kaztogo/ui-kit.html
- Кейс: https://slu1garden.github.io/portfolio/kaztogo.html
